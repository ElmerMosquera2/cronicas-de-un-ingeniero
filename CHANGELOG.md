# Changelog

Todos los cambios relevantes de este repositorio se documentan en este archivo.

El historial incluye la evolución de la visión del proyecto, su gobernanza, las obras que lo componen y cualquier cambio que afecte su estructura o contenido.

## 1.1.0

### Added
* **Nuevo documento de Gobernanza DOMER v2.3.0**: Incorporado el archivo que consolida la nueva versión del sistema de gobernanza, diseñado específicamente para su aplicación en desarrollo de software.

### Changed
* **Fusión metodológica (Merge)**: Evolucionado el marco de gobernanza general mediante la integración de la versión 2.2.0 (proveniente del repositorio *DOMER* original), el método agnóstico y los aprendizajes prácticos del trabajo de campo. El método agnóstico original se preserva como parte de esta base conceptual.

## 1.0.0

### Added
* Definida la **Visión Activa (VA-001)** de *Crónicas de un Ingeniero*, estableciendo la identidad, propósito y alcance del repositorio.
* Incorporada la primera versión del método **DOMER Agnóstico** como referencia de gobernanza en `domer/gobernanza-domer-agnostica.md`.
* Inicializada la estructura base del repositorio para albergar obras gobernadas mediante un sistema de documentación autocontenido.

### Changed
* Ninguno (versión inicial).
